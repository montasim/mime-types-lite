# Security policy

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Email [montasimmamun@gmail.com](mailto:montasimmamun@gmail.com) with:

- the affected version;
- impact and reproduction steps;
- any suggested mitigation.

You should receive an acknowledgment within 72 hours. Confirmed issues will be prioritized, fixed, and disclosed responsibly.

## Scope

This package maps strings and file extensions. It does not inspect file contents and must not be used as a security boundary for uploads. MIME values supplied by browsers or clients can be forged.
